# Zero Trust Mapping

This reference architecture aligns with common Zero Trust principles without treating Zero Trust as a product.

| Principle | Identity control |
|---|---|
| Verify explicitly | MFA, authentication strength, device/risk context |
| Use least privilege | group-based access, RBAC, eligible privilege |
| Assume breach | logging, sign-in analysis, token revocation, emergency access |
| Reduce standing trust | time-bound elevation and expiring exceptions |
| Protect non-human identities | workload identity ownership and rotation |
| Continuously validate | access reviews, dormant-account checks, policy monitoring |
